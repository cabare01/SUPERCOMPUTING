# Assignment 01 Essay
I want to learn high-performance computing to further my research capabilities. 
One of my current projects builds on the work of a prior doctoral student who used the W&M HPC for most of his big computational jobs.
A lot of the parallel analysis I have been doing to build on his work involves very large datasets and computationally intensive work that is becoming less and less efficiently manageable on my own computer.
Therefore, my goals for this course include developing a practical understanding of HPC that I can translate to my current research as well as future projects.
I also have no real formal training in computer or data science (neuroscience undergraduate major), so I want to make sure I am working with good computational habits, especially as I lean into the computational and bioinformatics side of much of my research.
I really just want to learn as many computational tools as possible and soak up all the reasoning behind each concept, not just memorize commands. 
I know I definitely learn better from seeing things done and practicing them myself, so I also think this course is set up well for my learning style.

The folder structure I created for this assignment is designed to separate different components of each assignment and make the organization of the project predictable. Keeping assignments in their own directories allows files, source code, data, documentation, and other materials to remain associated with the appropriate project rather than accumulating in one large, difficult-to-navigate directory.
This organization is important for reproducible research because the structure of a project is part of the information needed to understand how the work was performed. A well-organized directory makes it easier for someone else to identify where code, input files, output files, and documentation belong. My README also documents the commands used to create the project structure, meaning that the structure itself can be recreated rather than existing only as a collection of files on my computer.
It also makes it easier for me to return to my own work months later and understand what I was doing. 
The fact that the README documents the commands used to create the structure also means that the structure is reproducible rather than simply being the result of actions that happened once on my computer.
Documented code is also a key piece of reproducible research because it not only tells you how to get the same results but also exposes the assumptions, parameters, and other processing steps taken along the way that are often not explicitly shared in the methods.
I personally am dealing with some of that in my current project that is building on the past student's data. 
His scripts and output files were not always extensively documented in his lab notebook like his embryo work, so a significant part of reviving the project was reassembling his experimental and analytical pipelines.
Ultimately, I hope this course helps me become more independent and thoughtful as a computational researcher. 
I do not expect to become an HPC expert in one semester, but I want to build a foundation that I can continue using as my research becomes increasingly computational. 
In particular, I hope to become comfortable enough with HPC that I can recognize when a problem is better suited for a cluster than my personal computer and know how to approach solving it efficiently and reproducibly.
